AWS Linux Server Monitoring and Automated Alert System

A Python application that watches a Linux server and reports whether it is healthy or needs attention.

  • Linux
  • AWS
  • psutil
  • Logging
  • Git and GitHub
  • Collects CPU, memory, disk and network usage with psutil.
  • Uses configurable thresholds to mark the server HEALTHY or WARNING.
  • Writes monitoring activity and warnings to logs for troubleshooting.
  • Built for an AWS Linux EC2 instance, with CloudWatch monitoring and automated alerts planned next.
